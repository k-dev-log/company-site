# スカイライン・テクノロジーズ 企業サイト

「空の高さから、ビジネスを見渡す」をコンセプトにした、スカイライン・テクノロジーズの企業サイトです。`index.html` 1ファイルで完結する静的なシングルページです。

## サイトの概要

ページは次のセクションで構成されています。

| セクション | 内容 |
| --- | --- |
| 事業内容 | 提供しているサービスの紹介 |
| プロダクト | 主力プロダクト「Skyview」の紹介 |
| 導入事例 | 導入企業の声 |
| お知らせ | 新製品のリリースなどのニュース |
| 会社情報 | 会社の基本情報 |
| お問い合わせ | 相談・デモ依頼の連絡先 |

## ブラウザで HTML を開く手順

サーバーやビルドは不要です。

### 方法1: ファイルをダブルクリックする

1. このフォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

### 方法2: ターミナルから開く

macOS の場合は、このフォルダで次のコマンドを実行します。

```bash
open index.html
```

### 方法3: ブラウザにドラッグ&ドロップする

`index.html` を、開いているブラウザのウィンドウにドラッグ&ドロップします。

## ファイル構成

```
company-site/
├── index.html   # サイト本体
└── README.md    # このファイル
```
